# Security

This repository contains only source metadata, a small update script, and helper pages for sideloading Absorb.

If you find a security issue in **this repository** (for example a problem with the update workflow, generated source metadata, or redirect pages), please report it privately to the repository owner rather than opening a public issue with sensitive details.

For security issues in the **Absorb app itself**, please report them to the upstream Absorb project:

https://github.com/pounat/absorb

Do not include passwords, API keys, signing certificates, provisioning profiles, or other secrets in public issues.
